## 项目简介

love-info 是一个情侣个人信息展示网页：把两个人的基本资料、相识相恋的时间线、共同经历和照片，整理成一个随时可以打开、也可以发给朋友看的页面。需要注意的是，一旦部署到公网，页面内容对所有访客可见，并不存在「仅朋友可见」的访问限制。

相比社交平台上的零散动态，这个页面想把「我们」的信息集中在一处——资料、纪念日、故事、照片，随时更新，长期保存。

## 设计理念

视觉走**暖色明亮**路线，整体像一封手写的信：温柔、有呼吸感、有细节，不做冷色调，也不做暗色模式。

- **暖色基底**：奶油白、米色背景打底，蜜桃粉与暖橘做渐变点缀，点缀色不超过三个
- **柔软质感**：大圆角卡片、柔和弥散阴影、细描边，避免生硬的直线与硬阴影
- **字体层次**：标题用手写体或圆体点睛，正文用易读的无衬线体，靠字号与字重拉开层级
- **克制动效**：元素淡入上浮、悬停微交互、纪念日数字滚动，动效服务氛围而非炫技
- **内容即装饰**：照片、日期、手写式便签本身就是视觉元素，少用装饰性图标堆砌

> [!IMPORTANT]
> 全站仅提供亮色暖调配色，不实现暗色模式，避免维护两套主题、也保持温暖的统一气质。

## 功能特性

- **个人资料卡**：昵称、生日、星座、MBTI、爱好、职业等基本信息，双方并排展示
- **纪念日与计时**：恋爱天数实时累计，相识日、纪念日、生日倒计时
- **恋爱时间线**：按时间记录相识、表白、第一次旅行等关键节点
- **照片墙**：按主题或时间分组的照片展示，支持点击查看大图
- **每日一句**：情话、歌词或想对彼此说的话，每天自动轮换
- **留言与悄悄话**：把想对彼此说的话写进数据文件，由页面统一展示；纯静态站点没有登录与权限，若需要保密，请使用仅本地保留的私密数据文件（见[隐私说明](#隐私说明)）
- **共同心愿清单**：想一起做的事、想去的地方，完成一项勾选一项
- **响应式布局**：手机、平板、桌面均可正常浏览，暖色观感一致

## 技术选型

| 方面 | 方案 |
| --- | --- |
| 前端 | 纯静态页面（HTML + CSS + JavaScript），暂不引入框架 |

## 本地开发

> [!NOTE]
> 页面骨架（`index.html`、`data.json` 等）尚未创建，以下为完成后的预期用法。

克隆项目：

```bash
git clone https://github.com/3919500086/love-info.git
cd love-info
```

启动一个本地服务器。**不要用 `file://` 直接打开 `index.html`**：页面通过 `fetch` 读取 `data.json`，浏览器在 `file://` 协议下会因同源策略拦截请求，页面内容会是空白。

```bash
# 任选其一，均监听 8000 端口
python3 -m http.server 8000
npx serve . -l 8000
```

然后访问 <http://localhost:8000> 。

## 隐私说明

本仓库为公开仓库，页面与仓库内的数据文件都会发布到公网，**对所有访客可见，并非只有朋友能看到**。

因此约定两条数据边界（与[技术选型](#技术选型)保持一致）：

- 仓库内的 `data.json` **只放可以公开的内容**（昵称、纪念日、已获双方同意公开的照片等），改数据即改页面；
- 不便公开的内容放在本地私密数据文件（如 `data.private.json`），**仅本机浏览、绝不提交**，并应加入 `.gitignore`。GitHub Pages 只能读取仓库内的文件，被忽略的数据不会出现在线上页面。

> [!WARNING]
> 请勿将敏感信息（真实姓名、身份证号、详细住址、联系方式等）提交到仓库或发布到公网页面；照片发布前请确认双方均知情同意。若希望内容完全私密，请改用私有仓库，或不做公网部署、仅在本机或内网浏览。
