## 项目简介

love-info 是一个情侣个人信息展示网页：把两个人的基本资料、相识相恋的时间线、共同经历和照片，整理成一个随时可以打开、也可以发给朋友看的页面。需要注意的是，一旦部署到公网，页面内容对所有访客可见，并不存在「仅朋友可见」的访问限制。

相比社交平台上的零散动态，这个页面想把「我们」的信息集中在一处——资料、纪念日、故事、照片，随时更新，长期保存。

> [!NOTE]
> 首版页面已经实现，使用 `data.json` 中的示例数据和 `assets/img/` 中的示例图片，替换数据即可变成自己的页面。具体实现细节可能随使用继续调整。

## 设计理念

视觉走**暖色明亮**路线，整体像一封手写的信：温柔、有呼吸感、有细节，不做冷色调，也不做暗色模式。

- **暖色基底**：奶油白、米色背景打底，蜜桃粉与暖橘做渐变点缀，点缀色不超过三个
- **柔软质感**：大圆角卡片、柔和弥散阴影、细描边，避免生硬的直线与硬阴影
- **字体层次**：标题用手写体或圆体点睛，正文用易读的无衬线体，靠字号与字重拉开层级
- **克制动效**：元素淡入上浮、悬停微交互、纪念日数字滚动，动效服务氛围而非炫技
- **内容即装饰**：照片、日期、手写式便签本身就是视觉元素，少用装饰性图标堆砌

> [!IMPORTANT]
> 全站仅提供亮色暖调配色，不实现暗色模式，避免维护两套主题、也保持温暖的统一气质。

## 功能特性

- **个人资料卡**：昵称、生日、星座、MBTI、爱好、职业等基本信息，双方并排展示
- **纪念日与计时**：恋爱天数实时累计，相识日、纪念日、生日倒计时
- **恋爱时间线**：按时间记录相识、表白、第一次旅行等关键节点
- **照片墙**：按主题分组的本地照片，支持分类筛选、点击查看大图、键盘方向键与滑动切换
- **每日一句**：按日期自动轮换，也可以点「再读一句」手动翻看
- **留言与悄悄话**：`data.json` 中展示的留言 + 仅保存在本机浏览器的留言；纯静态站点没有登录与权限，需要保密的内容请使用仅本地保留的私密数据文件（见[隐私说明](#隐私说明)）
- **共同心愿清单**：想一起做的事、想去的地方，完成一项勾选一项，进度保存在本机浏览器
- **响应式布局**：手机、平板、桌面均可正常浏览，暖色观感一致

## 技术选型

| 方面 | 方案 |
| --- | --- |
| 前端 | 纯静态页面（HTML + CSS + JavaScript），无框架、无构建步骤 |
| 数据 | 全部内容集中在 `data.json`，改数据即改页面 |
| 交互 | 原生 JavaScript 渲染；心愿进度与本地留言使用 `localStorage` 保存 |
| 图片 | 示例图片已下载到 `assets/img/`，页面不依赖外部图床 |
| 配色 | 暖色系（奶油 / 蜜桃 / 暖橘），仅亮色模式，CSS 变量统一管理 |
| 字体 | Google Fonts（站酷快乐体 / Noto Sans SC / Quicksand），加载失败时回退系统字体 |
| 部署 | 计划使用 GitHub Pages（推送后自动上线，尚未接入） |

> [!IMPORTANT]
> 选型以「简单、可长期维护」为原则。后续功能若明显变重，再评估引入框架（如 Vue / React），并同步更新本文档。

## 数据说明

所有内容都在 `data.json` 中，常用字段如下：

| 字段 | 说明 |
| --- | --- |
| `site.names` | 两个人的名字，用于首屏标题 |
| `site.since` | 在一起的日期（`YYYY-MM-DD`），用于恋爱天数与实时计时 |
| `people[]` | 资料卡：`name`、`avatar`、`birthday`、`constellation`、`mbti`、`job`、`hobbies`、`tagline` |
| `anniversaries[]` | 纪念日：`type` 为 `countup`（累计天数）或 `countdown`（倒计时），`annual: true` 表示每年重复 |
| `timeline[]` | 时间线节点：`date`、`title`、`text`、`photo` |
| `photos[]` | 照片墙：`src`、`caption`、`group`、`date`，可选 `size: "wide"` 让照片横跨两列 |
| `quotes[]` | 每日一句，按日期自动轮换 |
| `wishes[]` | 心愿：`id`、`text`、`note`、`done` |
| `messages[]` | 展示在页面上的留言：`from`、`date`、`text` |

替换图片时，把文件放进 `assets/img/`，再把对应字段改成相对路径（如 `assets/img/our-trip.jpg`）即可。示例图片均来自 Unsplash，来源清单见 [`assets/img/CREDITS.md`](assets/img/CREDITS.md)；正式使用前请替换为自己的照片。

## 本地开发

克隆项目：

```bash
git clone https://github.com/3919500086/love-info.git
cd love-info
```

启动一个本地服务器。**不要用 `file://` 直接打开 `index.html`**：页面通过 `fetch` 读取 `data.json`，浏览器在 `file://` 协议下会因同源策略拦截请求，页面内容会是空白。

```bash
# 任选其一，均监听 8000 端口
python3 -m http.server 8000
npx serve . -l 8000
```

然后访问 <http://localhost:8000> 。

页面图片全部来自本地 `assets/img/`；字体通过 Google Fonts 加载，网络不可用时会回退到系统字体，不影响内容浏览。

## 隐私说明

本仓库为公开仓库，页面与仓库内的数据文件都会发布到公网，**对所有访客可见，并非只有朋友能看到**。

因此约定两条数据边界（与[技术选型](#技术选型)保持一致）：

- 仓库内的 `data.json` **只放可以公开的内容**（昵称、纪念日、已获双方同意公开的照片等），改数据即改页面；
- 不便公开的内容放在本地私密数据文件（如 `data.private.json`），**仅本机浏览、绝不提交**，并应加入 `.gitignore`。GitHub Pages 只能读取仓库内的文件，被忽略的数据不会出现在线上页面。

> [!WARNING]
> 请勿将敏感信息（真实姓名、身份证号、详细住址、联系方式等）提交到仓库或发布到公网页面；照片发布前请确认双方均知情同意。若希望内容完全私密，请改用私有仓库，或不做公网部署、仅在本机或内网浏览。
